# Bash — 7 Day Learning Journey

A hands-on 7-day journey to learn **Bash scripting, Linux automation, and security-oriented shell scripting**.

This folder documents my practical learning of Bash as part of my **Cybersecurity / DevSecOps** roadmap.

---

## 🎯 Objectives

By the end of this module, I aim to be able to:

- Understand the Bash shell and Linux command line
- Navigate and manage the Linux filesystem
- Write Bash scripts from scratch
- Use variables, conditions, loops, and functions
- Work with files and directories
- Process text and logs using command-line tools
- Understand pipes, redirection, and command substitution
- Handle script arguments and exit codes
- Automate common Linux administration tasks
- Work with Linux permissions and processes
- Build basic security-focused Bash scripts
- Create a practical Linux security auditing tool

---

## 🗺️ 7-Day Roadmap

| Day       | Topic                    | Focus                                             |
| --------- | ------------------------ | ------------------------------------------------- |
| **Day 1** | Linux Shell Fundamentals | Terminal, filesystem, commands                    |
| **Day 2** | Bash Basics              | Variables, input, output, arithmetic              |
| **Day 3** | Control Flow             | Conditions, loops, case statements                |
| **Day 4** | Files & Text Processing  | Pipes, grep, sed, awk, cut, sort                  |
| **Day 5** | Functions & Arguments    | Functions, parameters, exit codes, error handling |
| **Day 6** | Linux Automation         | System information, disk checks, backups          |
| **Day 7** | Security Automation      | Permissions, users, processes, logs, auditing     |

## 🔧 Practical Approach

This module follows a hands-on learning process:

```text
Learn
  ↓
Practice
  ↓
Build
  ↓
Document
  ↓
Commit
  ↓
```

## 🚀 Final Project

### Linux Security Audit

The final project is a Bash-based Linux security auditing script.

The tool will collect and analyze information such as:

- System information
- Current user
- User accounts
- File permissions
- Running processes
- Network configuration
- Disk usage
- Relevant log entries

# 1. Creating a Bash Script

A Bash script is a text file containing commands that Bash can execute sequentially.

A Bash script commonly uses the `.sh` extension.

Example:

```bash
script.sh
```

A basic Bash script:

```bash
#!/bin/bash

echo "Hello, Bash!"
```

The first line is called the **shebang**.

---

# 2. The Shebang

The shebang tells the operating system which interpreter should be used to execute the script.

```bash
#!/bin/bash
```

For Bash scripts, this specifies the Bash interpreter.

Another common approach is:

```bash
#!/usr/bin/env bash
```

This searches for Bash through the user's environment.

For this learning journey, the following form was primarily used:

```bash
#!/bin/bash
```

---

# 3. Executing a Bash Script

Suppose the script is:

```text
hello.sh
```

It can be executed by explicitly passing it to Bash:

```bash
bash hello.sh
```

A script can also be made executable.

First:

```bash
chmod +x hello.sh
```

Then:

```bash
./hello.sh
```

The `./` indicates that the script is being executed from the current directory.

---

# 4. `echo`

The `echo` command is used to display text or values.

Example:

```bash
echo "Hello World"
```

Variables can also be displayed:

```bash
name="Angad"

echo "$name"
```

Multiple values:

```bash
name="Angad"
age=21

echo "Name: $name"
echo "Age: $age"
```

---

# 5. Variables

Variables store values that can be reused throughout a script.

Example:

```bash
name="Angad"
```

The important Bash syntax is:

```text
variable=value
```

There must be **no spaces around `=`**.

Correct:

```bash
name="Angad"
```

Incorrect:

```bash
name = "Angad"
```

The value of a variable is accessed using `$`.

```bash
echo "$name"
```

---

# 6. Variable Naming

Bash variable names can contain:

- Letters
- Numbers
- Underscores

Examples:

```bash
username="admin"
user_count=10
server_name="web-server"
```

A variable should not begin with a number.

Good:

```bash
user1="admin"
```

Not valid:

```bash
1user="admin"
```

---

# 7. Quoting

Quoting is important in Bash because the shell interprets spaces and special characters.

## Double Quotes

```bash
name="Angad"

echo "Hello $name"
```

Variables are expanded inside double quotes.

Output:

```text
Hello Angad
```

## Single Quotes

```bash
echo 'Hello $name'
```

The variable is not expanded.

Output:

```text
Hello $name
```

### General rule

Use double quotes around variables when you want their value to be expanded safely:

```bash
echo "$name"
```

This becomes particularly important when working with filenames and user input.

---

# 8. Reading User Input

Bash provides the `read` command for accepting input.

Example:

```bash
read -p "Enter your name: " name

echo "Hello $name"
```

The script waits for the user to enter a value.

The value is stored in:

```bash
$name
```

---

# 9. Multiple Inputs

Multiple variables can be read at once.

```bash
read -p "Enter your first name: " first_name
read -p "Enter your last name: " last_name

echo "Name: $first_name $last_name"
```

This allows scripts to interact with users instead of relying entirely on hard-coded values.

# 10. Command Substitution

Command substitution allows the output of one command to be stored in a variable.

The modern syntax is:

```bash
$(command)
```

Example:

```bash
current_user=$(whoami)

echo "Current user: $current_user"
```

Another example:

```bash
current_date=$(date)

echo "Date: $current_date"
```

This is particularly useful in automation because information generated by Linux commands can be passed into Bash variables.

---

# 11. Environment Variables

Linux and Bash provide predefined environment variables.

Examples:

```bash
$HOME
$USER
$PATH
$PWD
$SHELL
```

View the current user's home directory:

```bash
echo "$HOME"
```

Current user:

```bash
echo "$USER"
```

Current working directory:

```bash
echo "$PWD"
```

Current shell:

```bash
echo "$SHELL"
```

The `PATH` variable contains directories where the shell searches for executable commands.

```bash
echo "$PATH"
```

---

# 12. Arithmetic Operations

Bash supports arithmetic using:

```bash
$(( ))
```

Example:

```bash
a=10
b=5

sum=$((a + b))

echo "$sum"
```

Basic operators:

| Operator | Operation |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulo/remainder |

Example:

```bash
a=20
b=6

echo $((a + b))
echo $((a - b))
echo $((a * b))
echo $((a / b))
echo $((a % b))
```

---

# 13. Incrementing a Variable

A variable can be incremented using:

```bash
((count++))
```

Example:

```bash
count=1

((count++))

echo "$count"
```

Output:

```text
2
```

Another form:

```bash
((count += 1))
```

# 14. Basic Script Structure

A simple Bash script can follow this structure:

```bash
#!/bin/bash

# Variables
name="Angad"

# Input
read -p "Enter your age: " age

# Output
echo "Name: $name"
echo "Age: $age"
```

The script contains:

```text
Shebang
   ↓
Variables
   ↓
Input
   ↓
Processing
   ↓
Output
```

This basic structure will become more powerful as conditions, loops, functions, and other Bash features are introduced.

## Simple Calculator


This introduced user input and arithmetic operations.

# 17. Important Bash Concepts Learned

### Bash interprets commands sequentially

Commands are generally executed from top to bottom.

### Variables do not use `$` when assigned

Correct:

```bash
name="Angad"
```

When accessing the value:

```bash
echo "$name"
```

### Spaces matter

Correct:

```bash
name="Angad"
```

Incorrect:

```bash
name = "Angad"
```

### Command substitution

```bash
user=$(whoami)
```

allows the output of a command to become a variable value.

### Arithmetic

```bash
result=$((a + b))
```

allows integer arithmetic directly in Bash.

# 🧠 Key Takeaways

- Bash scripts are executable collections of shell commands.
- The shebang specifies the interpreter used by the script.
- Variables store reusable values.
- Bash uses `$variable` to access a variable's value.
- Double quotes allow variable expansion.
- `read` accepts user input.
- `$(command)` captures command output.
- Environment variables provide information about the current shell and system.
- `$(( ))` performs arithmetic operations.
- `chmod +x` makes a script executable.
- Bash can turn repetitive Linux commands into automated workflows.

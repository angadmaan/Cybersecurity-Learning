## Overview

This repository contains my personal learning notes and documentation from the **Google Connect and Protect: Networks and Network Security** course offered by **Google** on **Coursera**.

Instead of simply completing the course and earning a certificate, I documented each module to reinforce my understanding of computer networks, network security, protocols, threats, vulnerabilities, and defensive security practices.

These notes summarize the key networking and cybersecurity concepts, technologies, tools, and best practices introduced throughout the course.

The goal of this repository is to track my cybersecurity learning journey while building a public portfolio of well-organized study material.

## Modules Covered

### Module 1 — Network Architecture

Introduction to computer networks and how devices communicate with each other.

This module covers fundamental networking concepts, network components, network architecture, and the role of protocols in enabling communication between devices.

📄 **Documentation:**

- `Module-1-Network-Architecture.md`

---

### Module 2 — Network Operations

Explores how networks operate and how data is transmitted between devices.

Topics include network protocols, IP addressing, ports, network devices, and common technologies used to connect systems and users.

📄 **Documentation:**

- `Module-2-Network-Operations.md`

---

### Module 3 — Network Security

Introduces the security challenges associated with computer networks and the techniques organizations use to protect their network infrastructure.

Topics include network attacks, vulnerabilities, security controls, firewalls, encryption, authentication, and other defensive mechanisms.

📄 **Documentation:**

- `Module-3-Network-Security.md`

---

### Module 4 — Network Security and Defense

Focuses on protecting networks against attacks and reducing security risks through monitoring, prevention, and layered security controls.

This module introduces concepts such as defense-in-depth, network monitoring, intrusion detection, security hardening, and secure network practices.

📄 **Documentation:**

- `Module-4-Network-Security-and-Defense.md`

## Learning Outcome

After completing this course, I developed a stronger understanding of how computer networks are designed, how devices communicate, and how network security controls help protect systems and data.

I learned important networking concepts such as the **OSI model, TCP/IP model, IP addresses, ports, protocols, DNS, network devices, and network communication**.

The course also helped me understand common network-based threats and attacks, along with defensive technologies and practices such as **firewalls, encryption, authentication, monitoring, intrusion detection, and defense-in-depth**.

This knowledge provides an important foundation for further learning in areas such as:

- Network Security
- Security Operations (SOC)
- Penetration Testing
- Cloud Security
- Incident Response
- Threat Detection
- Cybersecurity Operations
